## Увод у прозорске функције (Window Functions)

## Решења задатака - Први део

1. Рангирајте стадионе по просечној посети помоћу `DENSE_RANK`. Који су прва три?

```sql
SELECT stadium_name, ROUND(AVG(attendance)) AS avg_crowd,
       DENSE_RANK() OVER (ORDER BY AVG(attendance) DESC) AS crowd_rank
FROM matches_flat
GROUP BY stadium_name
ORDER BY crowd_rank;
```

Прво групишемо податке по стадиону и рачунамо просек (`GROUP BY`, `ROUND(AVG(...))`)\
Затим прозорска функција `DENSE_RANK` узима те вредности и додељује им ранг\
Прозорске функције се извршавају након `GROUP BY` (па ће редови табеле бити прво груписани, а над тим вредностима ће радити прозорска функција)\
Погледати редослед извршавања команди.

2. Пронађите највећу победу сваког клуба у сезони `2024/25` (највећа гол-разлика; ако их има више, најранија). Колико редова очекујете?

```sql
SELECT t.team_name, tm.goals_for, tm.goals_against, tm.kickoff_ts, tm.venue,
        ROW_NUMBER() OVER (PARTITION BY tm.team_id
                                ORDER BY tm.goals_for - tm.goals_against DESC, tm.kickoff_ts) AS rn
FROM team_matches tm JOIN teams t ON tm.team_id = t.team_id
WHERE tm.season = '2024/25'
QUALIFY rn = 1;
```

Зашто `ROW_NUMBER()`?\
Зато што на тај начин осигуравамо да ће само један ред бити "први"\
С обзиром на то да имамо и `tm.kickoff_ts` унутар `ORDER BY`, и функције `RANK` и `DENSE_RANK` би радиле посао.\
Када очекујемо само један ред коришћењем (`QUALIFY ... = 1`), једино `ROW_NUMBER` нам то увек омогућава, па је добра пракса користити њега уместо других функција за рангирање.

3. Ко је најбољи стрелац сваке сезоне?

```sql
WITH goals AS (
  SELECT m.season, e.player_id, COUNT(*) AS goals
  FROM match_events e JOIN matches m ON e.match_id = m.match_id
  WHERE e.event_type IN ('goal', 'penalty_goal')
  GROUP BY m.season, e.player_id
)
SELECT g.season, p.first_name, p.last_name, g.goals,
FROM goals g JOIN players p ON g.player_id = p.player_id
QUALIFY RANK() OVER (PARTITION BY g.season ORDER BY g.goals DESC) = 1;
```

Користимо `RANK` јер два (или више) играча су можда постигла исти број голова.\
У претходном задатку нам се тражила једна утакмица, али овде је пожељно да оба играча добију награду за најбољег стрелца сезоне.

4. Прве три судије по броју показаних жутих картона у свакој сезони. Шта се дешава ако двојица имају исти број?

```sql
WITH refs AS (
  SELECT season, referee_name, SUM(home_yellow_cards + away_yellow_cards) AS yellows
  FROM matches_flat
  GROUP BY season, referee_name
)
SELECT season, referee_name, yellows,
       RANK() OVER (PARTITION BY season ORDER BY yellows DESC) AS rnk
FROM refs
QUALIFY rnk <= 3
ORDER BY season, rnk;
```

Шта се дешава код изједначења?\
У сезони 2024/25, двојица судија имају исти број картона `(84, 80, 80)`\
Функција `RANK` обојици додељује друго место `(1, 2, 2)`. 
По овој функцији, следеће је 4. место, па је изостављено из резултата\
Да смо користили `DENSE_RANK` судија са 4. највећим бројем би добио ранг 3\
У том случају бисмо у резултату добили 4 судије

## Решења задатака - Други део

1. За сваку утакмицу прикажите посету и колико је изнад или испод просека свог стадиона. Која утакмица је највише изнад просека?

```sql
SELECT home_team, away_team, stadium_name, attendance,
       attendance - AVG(attendance) OVER (PARTITION BY stadium_name) AS vs_stadium_avg
FROM matches_flat
ORDER BY vs_stadium_avg DESC NULLS LAST;
```

Без прозорских функција бисмо морали да направимо посебан упит (`CTE` или подупит)\
Тај `CTE` би рачунао просек за сваки стадион, а онда бисмо то `JOIN`-овали са `matches_flat`

Овако уместо тога имамо `AVG() OVER(...)` који директно рачуна овај просек и проширује нашу табелу са њим\
Што га чини доступним за даље израчунавање, у овом случају разлике.

2. Који играч има највећи удео у минутима свог клуба у сезони `2024/25`?

```sql
WITH mins AS (
  SELECT s.player_id, s.team_id, SUM(s.minutes_played) AS minutes
  FROM player_match_stats s JOIN matches m ON s.match_id = m.match_id
  WHERE m.season = '2024/25'
  GROUP BY s.player_id, s.team_id
)
SELECT p.first_name, p.last_name, t.team_name, mins.minutes,
       ROUND(100 * mins.minutes / SUM(mins.minutes) OVER (PARTITION BY mins.team_id), 2) AS pct_of_team
FROM mins
JOIN players p ON mins.player_id = p.player_id
JOIN teams   t ON mins.team_id   = t.team_id
ORDER BY pct_of_team DESC;
```

`CTE` `mins` рачуна колико је сваки играч укупно одиграо минута (у ком тиму)\
Након тога `SUM(mins.minutes) OVER (PARTITION BY mins.team_id)` сабира минуте свих играча једног клуба (`PARTITION BY`)\
Што користимо као делилац за рачунање просека

3. Поред сваке утакмице прикажите колико утакмица је укупно судио њен судија. Колико је најмање, а колико највише?

```sql
SELECT match_id, referee_name,
       COUNT(*) OVER (PARTITION BY referee_name) AS referee_matches
FROM matches_flat
ORDER BY referee_matches;
```

Сваки ред представља једну утакмицу, а колона `referee_matches` гледа све утакмице које дели исти судија (и броји их)

4. Колики удео у укупном броју голова сезоне `2024/25` има сваки месец? Који месец има највећи удео?

```sql
SELECT MONTH(kickoff_ts) AS month,
       SUM(home_goals + away_goals) AS goals,
       SUM(SUM(home_goals + away_goals)) OVER () AS total_goals,
       ROUND(100 * SUM(home_goals + away_goals) / SUM(SUM(home_goals + away_goals)) OVER (), 1) AS pct_of_season
FROM matches_flat
WHERE season = '2024/25'
GROUP BY MONTH(kickoff_ts)
ORDER BY pct_of_season DESC;
```

Зашто овде пишемо `SUM(SUM(home_goals + away_goals))`?\
Први, унутрашњи `SUM` је класична агрегација\
Он сабира све голове унутар једног месеца (`GROUP BY MONTH(kickoff_ts)`)\
Спољашњи `SUM(...) OVER ()` је прозорска функција без партиција\
Она узима те месечне збирове и сабира их све заједно како би добила укупан број голова у целој сезони.\
Уз помоћ те рачунице, можемо израчунати проценат сваког месеца
