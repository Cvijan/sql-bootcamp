## Подупити, CTE и UNION

### Подупити (Subqueries)

- Упити унутар упита
    - Могу вратити једну вредност (скаларни упити, користе се уз `=`, `>`, `<`)
    - Могу вратити листу вредности (користе се уз `IN`)
    - Могу проверавати постојање редова (користе се уз `EXISTS` и `NOT EXISTS`)

### CTE (Common table expressions)

- Омогућава нам да напишемо упит, дамо му име и користимо га као привремену табелу у главном упиту
- Ово чини сложене упите читљивијим и омогућава агрегацију у више корака

### UNION и UNION ALL

- За разлику од `JOIN`-a који спаја табеле хоризонтално (тј додаје колоне), `UNION` спаја табеле вертикално (тј додаје редове)
- `UNION ALL` задржава све редове, док `UNION` уклања дупликате (што је спорије)

### Спајање по опсегу - range join

- Уместо знака једнакости, можемо додатно користити опсеге, што је кључно код анализе историјских података који имају датум почетка и краја (нпр. мандати тренера)

9. Помоћу CTE избројте картоне (жути, други жути и црвени) по утакмици, па израчунајте просечан број картона по утакмици у свакој сезони. Пазите на утакмице без иједног картона.

```sql
WITH cards AS (
  SELECT match_id, COUNT(*) AS n 
  FROM match_events
  WHERE event_type IN ('yellow_card', 'second_yellow', 'red_card')
  GROUP BY match_id
)
SELECT m.season, ROUND(AVG(COALESCE(c.n, 0)), 2) AS cards_per_match
FROM matches m 
LEFT JOIN cards c ON m.match_id = c.match_id
WHERE m.status = 'played'
GROUP BY m.season;
```

Ако само спојимо утакмице и догађаје, утакмице које немају картоне се неће ни појавити у резултату.\
Просек ће се рачунати само на утакмицама које имају картоне (биће вештачки висок)\
Зато прво у CTE `cards` бројимо картоне по утакмици\
Затим користимо LEFT JOIN из свих одиграних утакмица ка нашој CTE табели. (како не бисмо изгубили утакмице без картона).\
Ако утакмица није имала картоне, `cards.n` ће бити `NULL`\
Коришћењем `COALESCE(c.n, 0)` тај `NULL` претварамо у нулу, што омогућава функцији `AVG` да тачно израчуна просек.

10. Који клубови у сезони 2024/25 нису изгубили ниједну утакмицу код куће? Користите NOT EXISTS и проверите да ли резултат има смисла.

```sql
SELECT t.team_name FROM teams t
WHERE 
    EXISTS (
        SELECT 1 FROM matches m 
        WHERE m.home_team_id = t.team_id 
            AND m.season = '2024/25'
        )
    AND 
    NOT EXISTS (
        SELECT 1 FROM matches m
        WHERE m.home_team_id = t.team_id 
            AND m.season = '2024/25' 
            AND m.home_goals < m.away_goals
        );
```

Шта значи "није изгубио код куће"?\

Да бисмо добили валидан одговор, морамо прво доказати да је клуб уопште играо у тој сезони (`EXISTS`), а затим потврдити да нема поразе (`NOT EXISTS`).

5. Помоћу UNION ALL направите један ред по тиму по утакмици са бројем жутих картона тог тима. Који клуб је у сезони 2024/25 добио највише жутих картона?

```sql
-- Решење користећи matches_flat, илустровано претварање колона у додатне редове
WITH yellows AS (
  SELECT season, home_team AS team, home_yellow_cards AS yellows FROM matches_flat
  UNION ALL
  SELECT season, away_team AS team, away_yellow_cards FROM matches_flat
)
SELECT team, SUM(yellows) AS yellows FROM yellows
WHERE season = '2024/25'
GROUP BY team ORDER BY yellows DESC;
```

```sql
-- Решење користећи остале табеле
WITH cards AS (
       SELECT match_id, team_id, event_type FROM match_events
       WHERE event_type = 'yellow_card'
       UNION ALL
       SELECT match_id, team_id, event_type FROM match_events
       WHERE event_type = 'second_yellow'
```

Други приступ је "тежи" за базу јер иде у детаљне трансакционе податке, али је поузданији уколико сумњамо да збирна табела није редовно ажурирана или ако садржи грешке.

Напомена: Обратите пажњу да овде "губимо" информације о тимовима који нису имали жуте картоне у овој сезони.\
Ако бисмо желели и тај податак (ако уопште постоје) морали бисмо услов за сезону пребацити у `CTE` и проширити и са резултатима који броје 0 (`NULL`) у случају непостојања таквих догађаја.

6. Направите табелу лиге за сезону 2023/24. Ко је освојио лигу и са колико бодова?

```sql
WITH team_matches AS (
  SELECT season, home_team_id AS team_id, home_goals AS gf, away_goals AS ga FROM matches WHERE status = 'played'
  UNION ALL
  SELECT season, away_team_id, away_goals, home_goals FROM matches WHERE status = 'played'
)
SELECT 
    t.team_name,
    SUM(
        CASE 
            WHEN gf > ga THEN 3 
            WHEN gf = ga THEN 1 
            ELSE 0 
        END
    ) AS points,
    SUM(gf - ga) AS goal_difference
FROM team_matches tm 
JOIN teams t ON tm.team_id = t.team_id
WHERE tm.season = '2023/24'
GROUP BY t.team_name
ORDER BY points DESC, goal_difference DESC;
```

Подаци о утакмици су структурирани тако да су домаћин и гост у истом реду.\
Ако желите да групишете податке по тиму, то је немогуће урадити директно.\
Ми цепамо једну утакмицу на два реда (из угла сваког тима посебно), добијене резултате спајамо са `UNION ALL`\
Овај процес називамо "unpivot" - (смањујемо број колона, а повећавамо број редова)\
У оба случаја бележимо голове које је тим дао (`gf` - goals_for) и примио (`ga` - goals_against).\
Када имамо ово, рачунање саме табеле постаје једноставно помоћу условне агрегације.

Напомена: У овако дизајнираној табели немамо информацију да ли је тим био домаћин или гост. (што нам у овом задатку и није било важно)\
Табела има колоне: `season, team_id, gf, ga`\
Можемо искористити идеју из задатка 2 из овог дела како бисмо додали ову информацију.\
У првој табели додајемо: `'Home' as venue`\
У другој табели додајемо: `'Away' as venue`

8. Који тренер, са бар 10 утакмица, има највише бодова по утакмици?

```sql
WITH team_matches AS (
    SELECT home_team_id AS team_id, kickoff_ts,
        CASE WHEN home_goals > away_goals THEN 3 
             WHEN home_goals = away_goals 
             THEN 1 ELSE 0 
        END AS points
    FROM matches WHERE status = 'played'
    UNION ALL
    SELECT away_team_id AS team_id, kickoff_ts,
        CASE WHEN away_goals > home_goals THEN 3
             WHEN away_goals = home_goals THEN 1
             ELSE 0
        END AS points
    FROM matches WHERE status = 'played'
)
SELECT 
    ms.manager_name, 
    COUNT(*) AS matches, 
    ROUND(AVG(tm.points), 2) AS points_per_match
FROM team_matches tm
JOIN manager_spells ms 
    ON ms.team_id = tm.team_id
        AND DATE(tm.kickoff_ts) BETWEEN ms.start_date AND COALESCE(ms.end_date, DATE'9999-12-31')
GROUP BY ms.manager_name
HAVING COUNT(*) >= 10
ORDER BY points_per_match DESC;
```

Спајамо логику из шестог задатка ("unpivot")\
са логиком седмог задатка (спајање тима и датума са мандатом тренера)\
Приметимо да сада нема потребе за условом `IN` (јер смо урадили "unpivot" унутар нашег `CTE`)
