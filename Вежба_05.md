## Подупити, CTE и UNION

### Подупити (Subqueries)

- Упити унутар упита
    - Могу вратити једну вредност (скаларни упити, користе се уз `=`, `>`, `<`)
    - Могу вратити листу вредности (користе се уз `IN`)
    - Могу проверавати постојање редова (користе се уз `EXISTS` и `NOT EXISTS`)

### CTE (Common table expressions)

- Омогућава нам да напишемо упит, дамо му име и користимо га као привремену табелу у главном упиту
- Ово чини сложене упите читљивијим и омогућава агрегацију у више корака

### UNION и UNION ALL

- За разлику од `JOIN`-a који спаја табеле хоризонтално (тј додаје колоне), `UNION` спаја табеле вертикално (тј додаје редове)
- `UNION ALL` задржава све редове, док `UNION` уклања дупликате (што је спорије)

### Спајање по опсегу - range join

- Уместо знака једнакости, можемо додатно користити опсеге, што је кључно код анализе историјских података који имају датум почетка и краја (нпр. мандати тренера)

1. Колико играча је дало бар један аутогол? Користите IN.

```sql
SELECT COUNT(*) FROM players
WHERE player_id IN 
    (SELECT player_id FROM match_events WHERE event_type = 'own_goal');
```

Унутрашњи упит прави листу свих ID-јева играча који су дали аутогол.\
Главни упит затим броји играче чији се ID налази на тој листи.

2. Колико утакмица има више голова од просека свих утакмица? Користите скаларни подупит.

```sql
SELECT COUNT(*) FROM matches
WHERE home_goals + away_goals > 
        (SELECT AVG(home_goals + away_goals) FROM matches);
```

Подупит овде враћа само један број (просечан број голова на свим утакмицама, нпр. 2.81).\
База прво израчуна тај број, а затим филтрира утакмице које имају већи збир голова.

3. Саберите све голове у сезони 2024/25 из табеле `matches`. Затим спојите `matches` са `match_events` и саберите поново. Зашто се бројеви разликују?

```sql
SELECT SUM(home_goals + away_goals) FROM matches WHERE season = '2024/25';

SELECT SUM(m.home_goals + m.away_goals)
FROM matches m JOIN match_events e ON m.match_id = e.match_id
WHERE m.season = '2024/25';
```

Први упит враћа 1.092, а други 17.119.

Проблем умножавања, зашто други упит враћа ненормалан број голова?\
Када спојимо једну утакмицу (која има нпр. 3 гола) са табелом догађаја (која има нпр. 15 догађаја за ту утакмицу: картони, измене, голови)\
тај један ред из табеле утакмица се умножава 15 пута.\
Ако онда урадимо `SUM(home_goals)`, ми та иста 3 гола сабирамо 15 пута.\
Ово можемо решити сажимањем друге табеле (груписањем по броју утакмица пре `JOIN`-a), што ћемо видети у каснијим задацима.

5. Колико судија је бар једном досудило пенал, дат или промашен? Користите EXISTS.

```sql
SELECT COUNT(*) FROM referees r
WHERE EXISTS (
                SELECT 1 FROM matches m 
                JOIN match_events e ON m.match_id = e.match_id
                WHERE m.referee_id = r.referee_id 
                    AND e.event_type IN ('penalty_goal', 'penalty_miss')
            );
```

`EXISTS` ради тако што за сваког судију проверава да ли унутрашњи упит враћа било шта.\
Чим пронађе први пенал за тог судију, стаје са претрагом за њега и враћа `TRUE`.

Зашто `SELECT 1`?\
Код `EXISTS` уопште није битно које колоне враћамо у подупиту, битно је само да ли ред постоји.\
Зато је конвенција да се пише SELECT 1 или SELECT *, база података то оптимизује.

6. Помоћу CTE саберите домаће голове сваког клуба у сезони 2024/25, па изаберите клубове са више од 30. Колико их је?

```sql
WITH hg AS (
  SELECT home_team_id, SUM(home_goals) AS goals
  FROM matches WHERE season = '2024/25'
  GROUP BY home_team_id
)
SELECT COUNT(*) FROM hg WHERE goals > 30;
```

Део унутар `WITH ... AS (...)` припрема привремену табелу `hg` (`home_goals`).\
Главни упит онда чита из те припремљене табеле као да је права.

```sql
-- Задатак 6 урађен помоћу HAVING
SELECT home_team_id, SUM(home_goals) AS goals
FROM matches 
WHERE season = '2024/25'
GROUP BY home_team_id
HAVING SUM(home_goals) > 30;
```

7. Колико стадиона има просечну посету већу од просечне посете свих утакмица?

```sql
SELECT stadium_id, AVG(attendance) AS avg_crowd FROM matches
GROUP BY stadium_id
HAVING AVG(attendance) > (SELECT AVG(attendance) FROM matches);
```

Овде комбинујемо `HAVING` и скаларни подупит.\
`HAVING` филтрира груписане податке упоређујући их са глобалним просеком који рачуна подупит.

8. Колико играча је ушло у игру бар једном, а никад није добило картон?

```sql
SELECT COUNT(*) FROM players p
WHERE EXISTS (SELECT 1 FROM player_match_stats s WHERE s.player_id = p.player_id AND s.minutes_played > 0)
  AND NOT EXISTS (SELECT 1 FROM match_events e
                  WHERE e.player_id = p.player_id AND e.event_type IN ('yellow_card', 'second_yellow', 'red_card'));
```

Овде имамо два услова.\
Први (позитиван) потврђује да је играч уопште играо неки меч (`EXISTS`).\
Други (негативан) потврђује одсуство картона (`NOT EXISTS`).\
Да смо ставили само негативан услов, добили бисмо и играче који су целу сезону преседели на клупи или трибинама (јер ни они немају картоне).

9. Помоћу CTE избројте картоне (жути, други жути и црвени) по утакмици, па израчунајте просечан број картона по утакмици у свакој сезони. Пазите на утакмице без иједног картона.

```sql
WITH cards AS (
  SELECT match_id, COUNT(*) AS n 
  FROM match_events
  WHERE event_type IN ('yellow_card', 'second_yellow', 'red_card')
  GROUP BY match_id
)
SELECT m.season, ROUND(AVG(COALESCE(c.n, 0)), 2) AS cards_per_match
FROM matches m 
LEFT JOIN cards c ON m.match_id = c.match_id
WHERE m.status = 'played'
GROUP BY m.season;
```

Ако само спојимо утакмице и догађаје, утакмице које немају картоне се неће ни појавити у резултату.\
Просек ће се рачунати само на утакмицама које имају картоне (биће вештачки висок)\
Зато прво у CTE `cards` бројимо картоне по утакмици\
Затим користимо LEFT JOIN из свих одиграних утакмица ка нашој CTE табели. (како не бисмо изгубили утакмице без картона).\
Ако утакмица није имала картоне, `cards.n` ће бити `NULL`\
Коришћењем `COALESCE(c.n, 0)` тај `NULL` претварамо у нулу, што омогућава функцији `AVG` да тачно израчуна просек.

10. Који клубови у сезони 2024/25 нису изгубили ниједну утакмицу код куће? Користите NOT EXISTS и проверите да ли резултат има смисла.

```sql
SELECT t.team_name FROM teams t
WHERE 
    EXISTS (
        SELECT 1 FROM matches m 
        WHERE m.home_team_id = t.team_id 
            AND m.season = '2024/25'
        )
    AND 
    NOT EXISTS (
        SELECT 1 FROM matches m
        WHERE m.home_team_id = t.team_id 
            AND m.season = '2024/25' 
            AND m.home_goals < m.away_goals
        );
```

Шта значи "није изгубио код куће"?\
Ако само напишемо `NOT EXISTS` над утакмицама које је изгубио, добићемо и клубове који су испали из лиге прошле сезоне.\
Зато што они немају ниједну утакмицу ове сезоне, па технички нису ни изгубили ниједну.\
Да бисмо добили валидан одговор, морамо прво доказати да је клуб уопште играо у тој сезони (`EXISTS`), а затим потврдити да нема поразе (`NOT EXISTS`).
