## Агрегација и условна логика

### Агрегација и `GROUP BY`: 

- Када желимо да сумирамо податке (као што је проналажење укупних вредности, просека или максимума), користимо агрегатне функције (`SUM()`, `COUNT()`, `AVG()`, `MAX()`, `MIN()`). 
- Клаузула `GROUP BY` говори бази података како да групише редове пре примене ових функција. 
    - На пример, груписање по сезони (`season`) израчунаће агрегате за сваку сезону појединачно.

### Филтрирање група помоћу `HAVING`

- Док WHERE филтрира редове пре него што се групишу, HAVING филтрира резултате након што се изврши груписање и агрегација. 
- Ово је неопходно када желите да видите само групе које испуњавају одређени услов (нпр. просек већи од 2).

### Условна логика са `CASE WHEN`

- Омогућава вам да динамички креирате нове категоричке колоне (попут означавања утакмице са "Рано" или "Касно"). 
- Када се комбинује са агрегатним функцијама - што се често назива Условна агрегација — постаје моћан алат за бројање или сабирање само оних редова који испуњавају одређени услов
    - На пример, `SUM(CASE WHEN услов THEN 1 ELSE 0 END)`

## Решења задатака - Први део

1. Колико утакмица у свакој сезони нема пријављену посету? Решите без WHERE, само агрегатним функцијама.

```sql
SELECT season, COUNT(*) - COUNT(attendance) AS unreported
FROM matches_flat 
GROUP BY season 
ORDER BY season;
```

`COUNT(*)` броји сваки ред у групи, укључујући и оне са подацима који недостају.\
`COUNT(attendance)` броји само редове где колона за посећеност није NULL.\
Одузимањем ова два броја добијамо тачан број утакмица којима недостају подаци о посећености.

---

2. Највећа и најмања посећеност по стадиону

```sql
SELECT 
    stadium_name, 
    MAX(attendance) AS max_crowd, 
    MIN(attendance) AS min_crowd
FROM matches_flat 
GROUP BY stadium_name 
ORDER BY max_crowd DESC;
```

Групишемо записе по стадиону (`stadium_name`) и користимо `MAX()` и `MIN()` да извучемо екстремне вредности за сваки конкретан стадион.

---

3. Укупан број голова домаћина и гостију по сезони

```sql
SELECT 
    season, 
    SUM(home_goals) AS home_goals, 
    SUM(away_goals) AS away_goals
FROM matches_flat 
GROUP BY season 
ORDER BY season;
```

4. Утакмице и просечан број голова груписани по дану у недељи

```sql
SELECT DATE_FORMAT(kickoff_ts, 'EEEE') AS weekday, 
       COUNT(*) AS matches,
       ROUND(AVG(home_goals + away_goals), 2) AS goals_per_match
FROM matches_flat 
GROUP BY DATE_FORMAT(kickoff_ts, 'EEEE') 
ORDER BY matches DESC;
```

`DATE_FORMAT` извлачи пун назив дана у недељи из временске ознаке (`timestamp`).\
Упит затим групише податке по овом извученом дану.\
Део `AVG(home_goals + away_goals)` израчунава укупан број голова на утакмици пре израчунавања просека.\
`ROUND(x, 2)` заокружује резултат претходног на две децимале.

---

5. Судије које су показале 5 или више црвених картона

```sql
SELECT 
    referee_name, 
    SUM(home_red_cards + away_red_cards) AS reds
FROM matches_flat 
GROUP BY referee_name
HAVING SUM(home_red_cards + away_red_cards) >= 5 
ORDER BY reds DESC;
```

Овај упит сабира црвене картоне домаћина и гостију по утакмици, па их групише по судији.\
Затим користи `HAVING` клаузулу да филтрира сваког судију чији је укупан број црвених картона мањи од 5.

---

6. Тимови који у просеку постижу више од 2 гола код куће у сезони 2024/25

```sql
SELECT 
    home_team, 
    ROUND(AVG(home_goals), 2) AS avg_home_goals
FROM matches_flat 
WHERE season = '2024/25'
GROUP BY home_team 
HAVING AVG(home_goals) > 2 
ORDER BY avg_home_goals DESC;
```

`WHERE` клаузула филтрира скуп података на одређену сезону пре груписања. \
`HAVING` филтрира агрегиране резултате како би приказао само тимове који у просеку постижу више од 2 гола на домаћем терену.

7. Укупан број постигнутих голова по месецу

```sql
SELECT 
    MONTH(kickoff_ts) AS month, 
    SUM(home_goals + away_goals) AS goals
FROM matches_flat 
GROUP BY MONTH(kickoff_ts) 
ORDER BY goals DESC;
```

Функција `MONTH()` извлачи нумерички месец (1-12) из временске ознаке.\
То нам омогућава да групишемо утакмице по месецу (јер се сам `kickoff_ts` разликује од утакмице до утакмице)

## Решења задатака - Други део

1. Категоризација утакмица по терминима почетка

```sql
SELECT CASE WHEN HOUR(kickoff_ts) < 14 THEN 'Рано'
            WHEN HOUR(kickoff_ts) < 17 THEN 'Поподне'
            ELSE 'Вече' 
       END AS kickoff_slot,
       COUNT(*) AS matches
FROM matches_flat 
GROUP BY kickoff_slot;
```

`CASE WHEN` сврстава утакмице по сату почетка.\
Затим групишемо по овој категорији да бисмо пребројали колико утакмица спада у сваки временски термин.

---

2. Категоризација величине посећености

```sql
SELECT CASE WHEN attendance IS NULL  THEN 'Без података'
            WHEN attendance = 0      THEN 'Без публике'
            WHEN attendance < 20000  THEN 'Мала'
            ELSE 'Велика' END AS crowd_size,
       COUNT(*) AS matches
FROM matches_flat 
GROUP BY crowd_size;
```

Прво решавамо граничне случајеве (`NULL` и 0).\
Након тога одређујемо нумеричке прагове. \
Водите рачуна о редоследу, проверу са `NULL` радимо на почетку јер би у супротном могли изазвати неочекивано понашање.

---

3. Проценат утакмица по судији на којима је показан црвени картон

```sql
SELECT referee_name, COUNT(*) AS matches,
       SUM(
            CASE 
                WHEN home_red_cards + away_red_cards > 0 THEN 1 
                ELSE 0 
            END
       ) AS with_red,
       ROUND(100.0 * SUM(CASE WHEN home_red_cards + away_red_cards > 0 THEN 1 ELSE 0 END) / COUNT(*), 1) AS pct
FROM matches_flat 
WHERE status = 'played'
GROUP BY referee_name 
ORDER BY pct DESC;
```

Овде се уводи условно бројање. Сабирањем вредности `1` само када се деси црвени картон, добијамо укупан број утакмица са црвеним картоном.\
Дељењем овог збира са `COUNT(*)` и множењем са 100.0 израчунава се проценат.\
У изразу који рачуна проценат, морамо поновити калкулацију јер `with_red` још увек не постоји.

4. За сваку сезону: у колико утакмица је домаћин водио на полувремену, а у колико од њих је и победио?

```sql
SELECT season,
       SUM(CASE WHEN home_goals_ht > away_goals_ht THEN 1 
                ELSE 0 
            END
        ) AS led_at_ht,
       SUM(
            CASE WHEN home_goals_ht > away_goals_ht AND home_goals > away_goals THEN 1 
                ELSE 0 
            END
        ) AS led_and_won
FROM matches_flat 
GROUP BY season 
ORDER BY season;
```

Први `CASE` броји случајеве где је домаћи тим водио на полувремену.\
Други `CASE` додаје `AND` услов да провери да ли су такође победили на крају утакмице, ефективно пратећи стопу конверзије вођства у победу.

5. Категоризација извештаја са утакмица коришћењем поклапања текста

```sql
SELECT 
    CASE 
        WHEN match_report ILIKE '%late%' OR match_report ILIKE '%stoppage%' THEN 'Касна драма'
        WHEN match_report ILIKE '%penalty%'  THEN 'Пенал'
        WHEN match_report ILIKE '%red card%' THEN 'Црвени картон'
        WHEN match_report IS NULL            THEN 'Без наслова'
        ELSE 'Остало' 
    END AS tone,
    COUNT(*) AS matches
FROM matches_flat 
GROUP BY tone
ORDER BY matches DESC;
```

`ILIKE` се користи за претрагу стрингова без обзира на велика и мала слова.\
Џокер знак `%` осигурава да се кључна реч може појавити било где у тексту.\
Ова техника ефикасно извлачи сентимент или кључне догађаје из сирових текстуалних података.

## Решења задатака - Трећи део

1. Израчунавање гостујућих лигашких бодова

```sql
SELECT away_team,
       SUM(
            CASE 
                WHEN away_goals > home_goals THEN 3
                WHEN away_goals = home_goals THEN 1 
                ELSE 0 
            END
        ) AS away_points
FROM matches_flat 
WHERE season = '2024/25' 
        AND status = 'played'
GROUP BY away_team 
ORDER BY away_points DESC;
```

Ово симулира израчунавање табеле са бодовима.\
`CASE` наредба додељује 3 бода за победу у гостима и 1 бод за нерешен резултат.\
`SUM()` затим агрегира ове бодове за сваки тим (`GROUP BY away_team`) током сезоне.

---

2. Проценат утакмица где су оба тима постигла гол, груписано по месецу и години

```sql
SELECT 
    DATE_TRUNC('MONTH', kickoff_ts) AS month,
    ROUND(100.0 * AVG(CASE WHEN home_goals > 0 AND away_goals > 0 THEN 1 ELSE 0 END), 1) AS both_scored_pct
FROM matches_flat 
WHERE season = '2024/25'
GROUP BY DATE_TRUNC('MONTH', kickoff_ts) 
ORDER BY both_scored_pct DESC;
```

`DATE_TRUNC` заокружује временску ознаку на почетак месеца, раздвајајући "Феб 2024" од "Феб 2025" (За разлику од `MONTH()`).\
Коришћење функције `AVG()` над вредностима 1 или 0 математички даје размеру успешности, избегавајући потребу за `SUM(...) / COUNT(...)`.

---

3. Проценат попуњености стадиона

```sql
SELECT 
    stadium_name, 
    ROUND(AVG(100.0 * attendance / stadium_capacity), 1) AS avg_fill_pct, 
    COUNT(*) AS matches
FROM matches_flat 
GROUP BY stadium_name 
HAVING COUNT(*) >= 10 
ORDER BY avg_fill_pct DESC;
```

Ово израчунава однос посећености по утакмици.\
Налази просек тих односа и претвара их у проценат.\
Клаузула `HAVING` осигурава да рангирамо само стадионе који су били домаћини статистички значајног броја утакмица (10 или више).

---

4. Утакмице без голова на основу временских услова

```sql
SELECT 
    COALESCE(weather, 'непознато') AS weather_c, 
    COUNT(*) AS matches,
    SUM(CASE WHEN home_goals = 0 AND away_goals = 0 THEN 1 ELSE 0 END) AS goalless
FROM matches_flat 
GROUP BY weather_c
ORDER BY goalless DESC;
```

`COALESCE` гледа колону за време (`weather`) и, ако пронађе `NULL`, замењује га стрингом `'непознато'`.\
Ово спречава да `NULL` вредности испадну из наше анализе и групише све недокументоване временске услове у једну мерљиву категорију.
